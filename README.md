# Installation

The `R-universe` site for `nimbleJSextras` is
[here](https://dsjohnson.r-universe.dev/nimbleJSextras) and can be
installed from `R` with the command:

``` r
install.packages('nimbleJSextras', repos='https://dsjohnson.r-universe.dev')
```

It is also be directly installed from GitHub using the `remotes` package
with the command:

``` r
remotes::install_github('dsjohnson/nimbleJSextras/nimbleJSextras')
```

# Example analyses

There are examples of the Jolly-Seber model inference using this package
